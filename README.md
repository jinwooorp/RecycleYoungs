# 여기 창업해도 돼? - RecycleYoungs

## 프로젝트 소개

서울시 상권 정보와 공공데이터를 활용해 창업 후보지를 탐색하고 비교하는 서비스입니다.

다양한 업종의 예비 창업자에게 입지 선택과 창업 여부를 판단할 근거를 제공하는 것이 목표입니다.

**현재 MVP(Minimum Viable Product, 최소 기능 제품)는 서울시 카페 업종만 지원합니다.**

다른 업종은 향후 확장 대상으로 검토할 수 있습니다.

[구현 현황과 후속 범위](docs/PRD.md#현재-범위와-향후-확장)

## 화면 미리보기

### 장소 검색

검색창에 홍대입구역을 입력하면 역과 주변 장소의 이름·주소를 지도 옆 결과 목록에서 확인할 수 있습니다.

![홍대입구역을 입력한 검색창 아래에 지하철 노선별 역 이름과 주소를 표시한 데스크톱 지도 화면](docs/images/mvp-place-search.webp)

### 자치구·행정동 필터

지역 필터에서 마포구와 서교동을 선택하면 지도에 서교동 경계와 그 안의 카페 분포가 표시됩니다.

![마포구의 행정동 목록에서 서교동을 선택해 행정동 경계와 카페 클러스터를 표시한 지도](docs/images/mvp-region-filter.webp)

### 주변 탐색

홍대입구역을 중심으로 500m 반경을 설정하면 지도에 탐색 범위가 표시되고, 패널에서 가까운 카페부터 거리와 주소를 확인할 수 있습니다.

![지도에 홍대입구역 중심과 500m 반경을 표시하고 주변 카페 목록을 거리순으로 보여 주는 탐색 화면](docs/images/mvp-nearby-cafes.webp)

### 상권 분석

마포구 서교동의 지도와 함께 2026년 2분기 카페 점포 수, 당월 추정매출액, 지역 전체 유동인구를 확인할 수 있습니다.

![서교동 경계와 카페 클러스터가 표시된 지도 위에 2026년 2분기 핵심 지표와 점포 현황 그래프를 보여 주는 데스크톱 탐색 화면](docs/images/mvp-district-analysis.webp)

### 후보지 분석

홍대입구역, 합정역, 상수역을 A·B·C로 등록하면 지도에서 세 위치를 확인하고, 같은 500m 반경의 경쟁 카페 수와 각 후보지가 속한 행정동의 상권 통계를 비교할 수 있습니다.

![지도에 홍대입구역 A, 합정역 B, 상수역 C 마커를 표시하고 500m 반경 경쟁 카페 수와 소속 행정동 통계를 세 열로 비교하는 데스크톱 화면](docs/images/mvp-candidate-analysis.webp)

## 주요 기능

| 기능           | 할 수 있는 일                                                                                   |
| -------------- | ----------------------------------------------------------------------------------------------- |
| 지역·장소 탐색 | 자치구·행정동 경계를 확인하고, 장소명·지하철역·주소를 검색합니다.                               |
| 주변 카페 조회 | 지도에 보이는 카페를 살펴보고, 선택한 위치에서 500m 또는 1km 이내 카페를 거리순으로 확인합니다. |
| 상권 분석      | 선택한 지역 전체의 카페 점포 수·당월 추정매출과 업종 구분 없는 유동인구를 확인합니다.           |
| 후보지 비교    | 최대 3곳의 경쟁 카페 수를 같은 반경에서 비교하고, 각 후보지가 속한 행정동의 통계를 함께 봅니다. |

## 시스템 아키텍처

React 화면은 Spring Boot의 조회 API를 사용하고, 별도 ETL이 조회용 데이터를 준비합니다.

구성 요소와 저장·조회 흐름은 아키텍처 문서에서 확인할 수 있습니다.

웹 앱은 역할별로 정리되어 있습니다. 탐색 페이지가 지도와 패널을 조합하고, 주변 탐색·상권 분석·후보지 관리 코드는 각각의 기능 디렉터리에서 찾을 수 있습니다.

[시스템 아키텍처](docs/ARCHITECTURE.md) · [웹 소스 구조](docs/ARCHITECTURE.md#웹-소스-구조)

[요청 경로와 응답 계약](docs/API.md)

## 빠른 시작

화면부터 확인하려면 Node.js 24와 npm 11을 준비하고, 저장소 루트에서 웹 앱을 실행합니다.

```bash
cd apps/web
npm ci
npm run dev
```

[홈](http://localhost:5173/)에서 탐색을 시작할 수 있습니다.

지도를 보려면 Kakao Maps JavaScript 키를 설정합니다.

[지도 설정](docs/SETUP.md#kakao-maps-설정)

Backend를 `db` 프로필로 실행하면 Flyway가 새 DB에 테이블 구조를 적용합니다.

지역 목록과 상권 데이터는 별도로 준비합니다.

[개발 DB 데이터 준비](docs/SETUP.md#개발-db-게시-데이터)

| 목적                                         | 실행 안내                                          |
| -------------------------------------------- | -------------------------------------------------- |
| 테스트용 예시 데이터로 조회 API를 확인       | [합성 Demo](docs/SETUP.md#합성-demo)               |
| DB는 Docker에서, 웹 앱과 API는 로컬에서 실행 | [하이브리드 실행](docs/SETUP.md#로컬-db-준비)      |
