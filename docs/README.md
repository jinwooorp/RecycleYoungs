# 프로젝트 문서 안내

이 폴더는 사람이 프로젝트를 이해하고 실행·개발·배포하는 데 필요한 문서를 위한 공간입니다.

현재 프로젝트 소개, 기능, 데이터 해석의 한계와 기본 실행 방법은 [프로젝트 README](../README.md)에 있습니다. 상세 문서는 아래 범위에 따라 별도로 작성할 예정입니다.

## 작성 예정 문서

아래 파일명은 예정안이며 아직 상세 문서를 만들지 않았습니다.

| 예정 문서 | 다룰 내용 |
| --- | --- |
| `development.md` | 준비 환경, 로컬 실행, API 키 설정, 테스트, 일반적인 문제 해결 |
| `architecture.md` | 전체 요청 흐름, Backend·Frontend·ETL의 역할과 주요 코드 구조 |
| `data.md` | 원천 자료, 지표의 의미·단위·기간, 결측과 한계, 수집·갱신 흐름 |
| `deployment.md` | nginx, 배포 구성, CI/CD, 운영 확인과 복구 절차 |

## 작성 기준

- 독자가 해야 할 일과 확인할 결과를 중심으로 짧게 설명합니다.
- 현재 구현·검증한 내용과 계획·미확인 사항을 구분합니다.
- 실제 키·접속값·백업·private evidence는 문서에 넣지 않습니다.
- 상세 문서가 준비되면 이 안내와 프로젝트 README에서 연결합니다.

## 에이전트용 자료와의 구분

`agents/`에는 기존 프로젝트 현황·기술 계약·DB 안전 정책과 검증 기록을 보존합니다. 에이전트가 작업 기준과 이력을 확인하는 자료이며 일반 독자가 필수로 읽어야 하는 문서는 아닙니다.

사람용 상세 문서에는 필요한 설명을 독립적으로 정리하며, `agents/`의 긴 작업 기록을 읽어야만 내용을 이해할 수 있게 구성하지 않습니다. 화면 이미지는 기존 `images/` 경로를 유지합니다.
