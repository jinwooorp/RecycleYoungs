# RecycleYoungs 문서 안내

RecycleYoungs는 다양한 업종의 예비 창업자가 공공데이터로 후보지를 탐색하고 상권을 비교하도록 돕는 것을 목표로 합니다. 현재 MVP는 서울의 카페 업종만 지원합니다.

처음 합류했다면 [빠른 시작](../README.md#빠른-시작)에서 웹 앱을 열어 보고, [개발 가이드](development.md#팀원-클론과-실행-방식)에서 작업에 맞는 실행 환경을 고릅니다.

## 작업별 읽는 순서

| 작업 | 읽는 순서 |
| --- | --- |
| 로컬에서 개발·검증하기 | [개발 가이드](development.md)에서 도구, 실행 방식, 지도 설정을 확인한 뒤 [빌드·테스트·품질 검사](development.md#빌드테스트품질-검사)를 봅니다. |
| 화면 동작과 요구사항 확인하기 | [서비스 명세](service-spec.md)에서 탐색 흐름, 후보지 비교, 데이터 표시 정책을 확인합니다. |
| API를 사용하거나 DB 구조 확인하기 | [데이터 설계](data-design.md)에서 스키마·원천·집계 정책을 확인하고 [REST API 계약](data-design.md#행정구역-rest-api-계약)에서 요청 형식, 응답과 오류를 확인합니다. |
| 공공데이터 확인·적재하기 | [ETL 가이드](etl-guide.md)에서 원천, 파일·API 검증, 수동 게시와 재실행 절차를 확인합니다. 판본이나 게시 결과가 필요하면 아래의 검증 기록을 봅니다. |

## 현재 상태

| 구분 | 내용 |
| --- | --- |
| 구현 완료 | 서울 카페 탐색, 구·동 상권 통계, 최대 3개 후보지 비교, 통계 6종의 API·파일 기반 수동 ETL, 로컬 실행과 합성 Demo, GitHub Actions CI |
| 개발 예정 | 상권 분석 확대, 화면의 다중 자치구 선택, 정기 데이터 갱신, 운영용 Compose와 배포 자동화 |
| 미확정 | 카페 외 지원 업종과 도입 시점, 전분기 증감 공개 여부, 공식 경계 대체 API의 동등성, 행정동 파생 통계의 산출·표시 기준 |

화면은 2026년 2분기와 이전 1분기를 조회합니다. 점포·추정매출·유동인구의 증감 숫자는 비교 기준이 확인될 때까지 공개를 보류합니다. 공식 자치구 값은 자치구 원천을 사용하고, 누락 행·NULL·실제 0을 구분합니다. [서비스 표시 정책](service-spec.md#상권-통계의-표시와-전분기-정책) · [공식 자치구 통계와 집계 정책](data-design.md#공식-자치구-통계와-집계-정책)
