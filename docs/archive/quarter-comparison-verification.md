# 2026년 2분기·1분기 통계 비교 검증

2026-11-05 로컬 개발 DB와 Backend를 **읽기 전용**으로 검증했습니다. 두 분기의 자료는 있지만 비교 가능성의 근거가 충분하지 않아 **현재 세 지표 모두 증감 숫자를 공개하지 않습니다**. 분기 조회·정확한 계산 기능과 비교 불가 안내를 분리했습니다. 점수의 `NOT_APPROVED` 상태와는 별개입니다.

## 공식 원천 후속 대조 — 2026-11-05

[공식 원천 후속 검증표](official-source-verification-20261-20262.md)에서 기존 부족 근거를 추가 확인했습니다. 통계 CSV 6개와 행정동 경계 ZIP은 조회일의 공식 응답과 실제 로컬 바이트가 일치했습니다. 두 분기 대상 통계 2,692행의 채택 필드·정밀도·실제 출처도 기존 판독기와 읽기 전용 DB로 대조해 차이 0건을 확인했습니다. 아래의 초기 API 24건·구현 테스트 322건을 이번에 다시 실행한 것은 아닙니다.

새로 해소된 것은 **현재 공식 출력과 로컬 파일의 연결** 및 기본 내보내기 조건입니다. 행정동 점포·매출의 20251~20262 범위는 포털 기본 최근 기간 필터의 조회 당시 결과입니다. 2026-07-03 제공기간 변경 공지의 대상 43개에는 통계 6종이 포함되지만 경계 OA-22160/22161은 포함되지 않습니다. 원본 생성·공식 릴리스 이력, 두 분기의 경계 유효 기간과 매출·인구 산정 기준까지 확인한 것은 아닙니다.

누락 4동은 조회일 공식 매출 출력에도 두 분기 모두 없지만 **공식 사유는 여전히 미확인**입니다. 점포의 제한적 비교 가능·공개 보류, 매출·인구의 비교 불가 판단과 코드의 `unverified` 정책을 유지합니다. 추가 자료 요청은 [공개 준비의 갱신된 미발송 문의](../score.md#제공기관-문의-초안과-미발송-상태)에 정리했습니다.

예를 들어 점포 수는 마포구 2,320 → 2,306, 서교동 705 → 702, 성동구 1,026 → 1,025, 성수1가1동 77 → 77입니다. 이는 데이터 존재 확인이며 비교 공개의 승인 근거로 사용하지 않습니다.

## 구현 및 계산 정책

- 현재 `20262`, 이전 `20261`을 별도 요청·응답 식별자로 검증합니다. 구/동·지역·분기별 요청을 분리하고 취소 및 늦은 응답을 차단합니다. 탭 변경은 재조회하지 않으며 오류 재시도는 해당 분기·지표에 한정합니다.
- `statistic-comparison.ts`의 실제 공개 정책은 세 지표 모두 `unverified`입니다. 단순 조회 지원이나 계산 단위 테스트 통과를 원천 검증으로 취급하지 않습니다. 데이터·측정값 누락과 조회 오류도 0으로 대체하지 않습니다.
- 검증된 입력에 사용하는 계산은 BigInt 기반 십진수 연산입니다. 증감량은 두 원본 중 긴 소수 자릿수를 유지하며 원본 문자열·후행 0을 변경하지 않습니다. 증감률은 `(현재-이전)/이전×100`을 소수 첫째 자리까지 표시하며 정확히 절반이면 0에서 먼 방향으로 반올림합니다. 크기로 임의 제한하지 않습니다.
- 이전 값 0·현재 양수는 증감량만 계산하고 증감률은 계산 불가입니다. 양쪽 0은 변동 없음입니다. NULL·한 분기 누락·식별자 불일치·미검증 원천은 숫자 증감을 공개하지 않습니다.
- 매출을 분기 합계·월평균으로 환산하지 않고 유동인구를 고유 방문객·카페 이용객·반경 인구로 설명하지 않습니다. 증감을 창업 유불리·점수·순위로 해석하지 않습니다.

## 구현 검증

Node.js 24.22.2에서 20개 파일·322개 테스트, lint, format:check, build, `git diff --check`를 통과했습니다. 분기·구/동·업종 식별, 정밀도·반올림·0·NULL, 개별 오류·재시도, 요청 경합·패널 재열기, 탭 무재조회, 미검증 증감 숨김과 점수 미호출을 검증했습니다.

실제 Kakao Maps와 Backend로 위 네 지역을 각각 1440px·800px·390px에서 확인했습니다. 카드·페이지의 가로 넘침과 관찰 중 오류는 없었습니다. 탭 전환은 통계를 재조회하지 않았습니다. 이전 분기 503과 긴 소수는 **브라우저 응답에만 주입한 테스트 조건**이며 실제 서버 장애나 실데이터라고 주장하지 않습니다. 503 상태에서도 현재 통계는 유지됐고 재시도는 실패한 이전 분기 요청 하나만 발생했습니다. 긴 소수도 모바일 카드 안에서 줄바꿈됐습니다.
