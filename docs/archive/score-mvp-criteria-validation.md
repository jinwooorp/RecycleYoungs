각 분기의 지역 코드는 현재 정상 경계와 연결한 결과입니다. 존재하는 네 필수 측정값의 NULL·음수·비유한 값은 모두 0건입니다. 행 부재는 별도 결측으로 유지했습니다. `20262` 공통 25구·421동의 실제 0은 폐업률 99건이며, 매출·인구·점포 수 0은 없습니다.

매출 누락 면목5동(`11260550`)·하계2동(`11350612`)·북가좌1동(`11410710`)·개포1동(`11680660`)은 6분기 모두 제외됩니다. `20251`에는 둔촌1동(`11740690`)도 없습니다. 누락 원인은 확정하지 못했으며 0·인접 지역·다른 분기로 대체하지 않았습니다.

**호환성 판단:** 같은 자료별 배치·컬럼·코드와 `20251~20262`의 입력 존재는 확인했습니다. 그러나 현재 DB의 경계·소속은 과거 분기별 경계 이력이 아니며, 판본별 매출 모집단·정확한 기간, 폐업률 분모·반올림, 인구 배분·중복 기준과 과거 공간 경계의 동등성은 확인하지 못했습니다. 기존 [기간·판본 정책](../district-statistics-policy.md#기간과-원천-판본)의 미확인 범위를 해소하지 못했으므로 **과거 A 점수·분기 간 순위 상관·상위 집합 변화는 계산하지 않았습니다.** 분기를 묶거나 안정적이라고 결론 내리지 않습니다.

**집단 효과만 분리한 검산:** 전 기간 코드·입력 교집합은 구 25·동 420개입니다. 동일한 `20262`에서 둔촌1동을 제외한 420동을 다시 정규화했습니다. 공통 420동 안에서 기존 점수와 재계산 점수를 비교하면 상관 0.99999129, 평균 순위차 0.24·최대 3등, 최대 점수차 0.09점, 상위 5곳 5/5·상위 약 10% 42/42 중복입니다. 상관을 4자리로 반올림하면 1.0000이지만 순위가 완전히 같다는 뜻은 아닙니다. 원래 421동의 평균 순위와 직접 비교해도 최대 3등 차이입니다. 미래 기간 비교에서는 이런 집단 효과와 입력 변화 효과를 구분해야 합니다.

## 3. 계산·집계 정의

- 점포 방향·비중 비교는 유한 비음수 S·F·N·c와 N>0인 동일한 25구·421동입니다. S·F·N·c는 기존 기술 부록의 매출·인구·전체 점포 수·원천 폐업률입니다. 구·동은 따로 순위 정규화합니다. 폐업률을 재계산하거나 100% 상한을 적용하지 않습니다.
- 작은 값부터 동률 평균 순위를 매겨 `R=(r−1)/(n−1)`을 사용합니다. 기존 A·E는 `z=(R(S),R(F),1−R(N),1−R(c))`, 비중 `(0.30,0.30,0.20,0.20)`입니다. 방향 비교안은 A에서 세 번째 값만 `R(N)`으로 바꿉니다. log/winsor나 새로운 결합 모델은 사용하지 않았습니다.
- A는 정확한 유리수 가중합, E는 기존 관측 기준점·가중 제곱거리 정의를 사용합니다. E의 비중은 거리 제곱합에 한 번 적용하며 별도 벡터 정규화를 하지 않습니다. 기본·가중치 실험에서 기준점과 정규화값은 고정합니다.
- 순위는 반올림 전 점수의 내림차순 동률 평균 순위입니다. E 순위는 정확한 `d−²/d+²`로 판정하며 이번에는 좋은 기준점까지 거리가 모두 양수였습니다. 점수별 기여를 임의로 더해 E를 설명하지 않습니다.
- 상위·하위 약 10%는 `ceil(n×0.10)`번째 관측값을 경계로 동률을 포함합니다. 매출 하위는 원본 매출의 작은 쪽, 종합 상위는 큰 점수 쪽입니다. 기본값과 8개 변경안 모두 구 3·동 43곳입니다. 상위 5도 경계 동률을 포함했으며 방향 비교에서는 각 5곳입니다. 이 구간은 진단용이며 산출 제외 정책이 아닙니다.
- Spearman은 동률 평균 순위 사이의 Pearson 상관, 순위차는 평균 순위 차이의 절댓값입니다. 원본 Pearson은 규모의 선형 관계를 별도로 봅니다. 별도 명시가 없으면 표의 점수·분포는 소수 2자리, 상관 4자리, 순위는 필요한 경우 0.5를 표시하며 새 표는 표시만 `ROUND_HALF_UP`을 사용합니다. 내부 Fraction·Decimal 계산값은 반올림하지 않았습니다.

## 7. 판단과 다음 확인

- **확인한 사실:** 방향 변경은 상위 선택과 점수 폭을 바꿨습니다. 기본 A·E의 저매출 상위 진입은 없지만 A의 작은 비중 변경에서 진입이 생깁니다. 6분기 입력·출처와 공통 코드 집합은 확인했으나 과거 순위 비교 전제는 충족하지 못했습니다.
- **MVP 제안:** 기여를 설명할 수 있는 A를 검증 기준선으로 유지합니다. B·C의 분모·D의 0·E의 추가 복잡성이 현재의 원천 의미·보상 합의 문제를 해결하지는 않습니다. 점포 증가안이나 새 비중을 최종 v1으로 선택하지 않습니다.
- **보상 제한 제안:** 원천 모집단·기간 검증 후 최소 매출 조건, 매출 순위에 따른 상위 표시 제한 또는 경고를 별도 비교할 수 있습니다. 절대 매출 하한은 지역 규모·계절·판본에 민감하고, 상대 하위 10% 제외는 언제나 일부 지역을 떨어뜨리며 집단·순위도 바꿉니다. 이번에는 어느 제한도 적용·계산·채택하지 않았습니다. 산출 불가·경고·정상 점수의 API 의미도 별도 합의가 필요합니다.
- **미확정:** 수요 탐색과 경쟁 부담의 상대적 목적, 점포 방향, 비중·보상 허용 범위, 과거 공간 경계·기간·정의 호환, 4~5동 매출 누락 이유, 실제 창업 성과와의 관계입니다. E를 대안으로 자동 채택하거나 임의 임계값을 최종 정책으로 정하지 않습니다.
- **다음 순서:** 제공기관 판본별 명세·과거 경계 대조 → 호환 분기에 한해 전체/고정 집단의 A 비교 → 사전 합의한 보상 제한·비중 민감도 → 독립 성과 검증입니다. 이 전에는 원본 지표와 한계를 중심으로 보여 주는 MVP 설명을 권합니다.
