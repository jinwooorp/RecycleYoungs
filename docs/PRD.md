# 제품 요구사항

서비스 기획과 화면 개발을 위한 문서입니다.

RecycleYoungs의 목표는 다양한 업종의 예비 창업자가 공공데이터와 상권 정보를 활용해 후보지를 고르고 비교하도록 돕는 것입니다.

사용자는 주변 경쟁 환경과 지역 통계를 확인하고, 후보지를 같은 조건으로 비교할 수 있어야 합니다.

현재 MVP는 서울의 카페 업종만 지원합니다.

## 상세 이용 흐름

### 메인 페이지

랜딩(`/`)은 지역·장소 검색, 경쟁 카페 확인, 상권 통계와 후보지 비교를 화면 예시로 소개합니다.

**시작하기**로 `/explore`를 열면 지도를 불러옵니다.

알 수 없는 경로의 404 화면에는 홈·탐색 링크가 있습니다.

### 탐색 페이지

탐색은 서울특별시를 대상으로 합니다.

지도는 탐색 화면 전체를 채웁니다. 상단 왼쪽에 홈과 장소 검색을, 오른쪽에 공통 지역 필터를 표시합니다. 하단 중앙 Dock에서 **주변 탐색**, **상권 분석**, **후보지 분석**을 전환합니다.

상세 패널은 처음에 접혀 있고 메뉴나 닫기 버튼·Escape로 닫을 수 있습니다.

닫을 때 포커스가 패널 안에 있으면 선택 메뉴로 돌립니다.

한 번에 한 패널이 Dock 위에 열립니다. 1024px 이상에서는 세 메뉴에 공통으로 최대 840px 너비와 65dvh 높이를 적용합니다. 더 좁은 화면에서는 높이가 최대 50dvh인 하단 시트를 사용합니다. 화면에서 쓸 수 있는 공간이 작거나 지도에서 위치를 고르는 중에는 패널을 줄입니다. 긴 콘텐츠는 패널 안에서 스크롤합니다. 메뉴를 다시 열면 패널 맨 위에서 시작하고, 열린 패널의 분기나 데이터가 바뀌면 현재 스크롤을 유지합니다.

패널이 열려도 지도 크기와 현재 카메라를 유지합니다. 패널에 가리지 않은 지도는 계속 조작할 수 있고, 일반 지도 클릭으로 패널이 닫히지 않습니다. 검색 위치나 후보지를 명시적으로 확인할 때 표식이 검색 결과나 패널에 가리면 한 차례 보정합니다. 모션 감소 설정에서는 패널 전환이 즉시 적용됩니다.

#### 지도와 현재 위치

기본 지도 중심은 서울시청입니다.

첫 진입 시 브라우저에 위치 권한을 요청하고 Kakao SDK로 현재 위치가 서울임을 확인하면 이동해 표식으로 표시합니다.

권한 거부·오류·서울 외부·서울 소재 확인 실패 시 현재 지도 상태를 유지합니다.

위치 성공과 일반 안내는 뷰포트 가로 중앙에 4초간 표시합니다.

넓은 화면에서는 상단 검색·필터 아래에, 좁은 화면에서는 지도 조작 버튼 아래에 표시합니다.

위치 조회 오류는 별도 경고와 재시도 버튼으로 안내합니다.

**내 위치로 이동**으로 다시 시도할 수 있습니다.

늦은 위치 응답은 그사이의 지도 조작이나 지역·장소·후보지 선택을 덮어쓰지 않습니다.

현재 위치 좌표는 브라우저 메모리에서 사용하며 별도 수집·저장·로그를 남기지 않습니다.

SDK 키 누락, 로딩, 실패는 화면에서 구분하고 실패 시 재시도를 제공합니다.

[Kakao Maps 설정](SETUP.md#kakao-maps-설정)

#### 지역 필터

자치구를 먼저 선택하고 해당 구의 행정동을 고릅니다.

구를 바꾸면 동 선택이 초기화됩니다.

각 필터의 **전체**는 해당 단계의 제한을 해제합니다.

구를 선택하고 동을 **전체**로 두면 구 전체가 분석 단위가 됩니다.

지역을 선택하면 해당 구·동의 경계로 이동하고 강조합니다.

경계 조회 중이나 실패 상태에서는 이전 강조를 숨깁니다.

목록·경계는 로딩·빈 결과·오류를 구분하고 실패 시 재시도할 수 있습니다.

지도 조작만으로 지역 필터는 변경되지 않습니다.

[행정구역 조회 계약](API.md#행정구역-rest-api-계약)

#### 장소 검색

장소명·지하철역 등 키워드와 도로명·지번주소를 검색합니다.

첫 페이지에서 최대 15개를 표시하며 서울 소재 결과를 우선합니다.

결과를 고르면 기존 지역 경계와 반경 중심을 정리하고 검색 위치를 표시합니다.

상권 분석은 서버 경계가 좌표를 포함하는 자치구와 소속 행정동이 각각 하나일 때 행정동 통계를 표시합니다.

행정동을 확정할 수 없으면 유일한 자치구의 통계를 표시합니다.

자치구를 확정할 수 없는 경우 지역 필터로 직접 선택할 수 있습니다.

**이 위치 주변 카페 보기**를 누르면 선택 결과가 반경 탐색의 중심이 됩니다.

기존 500m·1km 설정을 유지하며 구·동 필터는 반경 조회에 전달하지 않습니다.

구·동을 다시 고르면 이전 검색 표식과 반경 중심을 정리하고 새 지역의 경계로 이동합니다.

검색과 소속 조회는 각각 오류와 재시도를 제공합니다.

## 카페 조회와 상권 통계

| 조회                | 범위와 표시                                                                                                                                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 현재 지도 영역 카페 | 화면의 사각 영역과 선택 구·동 경계에 해당하는 개별 카페를 표시합니다. 구 미선택 상태에서는 지도 레벨 4 이하로 확대해야 조회합니다. 최대 200곳의 마커·목록과 서버 전체 건수를 구분합니다.               |
| 선택 지점 주변 카페 | 지도에서 고르거나 검색에서 넘긴 지점을 중심으로 500m 또는 1km 반경의 카페를 조회합니다. 화면에 중심점과 원을 표시하고 서버 거리순을 유지합니다. 구·동 선택은 유지하지만 이 조회에는 적용하지 않습니다. |
| 상권 분석           | 선택한 자치구 또는 행정동 **전체**의 점포·당월 추정매출·유동인구를 표시합니다. 점포·매출은 카페 업종, 유동인구는 업종 구분 없는 지역 전체 기준입니다. 구 통계는 공식 자치구 원천을 사용합니다.         |

주변 카페 조회는 서울 공공데이터를 대상으로 합니다.

지도에서 고른 중심점은 주소를 확인할 수 없으면 선택 위치로 표시합니다.

검색에서 넘긴 중심점은 해당 장소명·주소를 사용합니다.

중심점과 반경은 탐색 상태로 유지되며 후보지로 추가할 때만 후보지 목록에 저장됩니다.

카페의 위치·거리·주소 등 제공된 정보만 표시합니다.

지도에서 묶인 마커의 수는 표시 중인 마커 수입니다.

지역 전체 통계와 선택 지점 주변 카페 수는 화면에서 각각의 범위로 표시합니다.

### 상권 통계의 표시와 전분기 정책

탐색에 진입하면 게시 통계 행에서 조회 가능한 분기 목록을 가져옵니다.

기본 분기는 자치구·행정동 두 수준에서 점포·추정매출·유동인구가 모두 있는 가장 최신 분기입니다. 이런 분기가 없다면 목록의 최신 분기를 사용합니다.

상권 분석과 후보지 분석의 **통계 기준 분기**에서 일부 지표만 게시된 분기도 선택할 수 있습니다. 지역·메뉴·후보지가 바뀌어도 선택을 유지하며, 새로고침이나 새 탭에서는 API 기본값으로 시작합니다.

구·동 두 수준에서 세 지표가 모두 게시되지 않은 분기는 선택지에 **일부 지표**로 표시합니다. 선택하면 서울 전체 게시 현황을 수준별로 안내하며, 선택 지역 자료의 유무는 조회 결과에서 확인합니다.

분기 목록을 새로고침했을 때 선택한 분기가 사라졌다면 안내를 표시하고 다시 선택할 때까지 통계를 기다립니다. 목록 로딩·오류·빈 목록에서도 지도와 반경 카페 탐색을 할 수 있습니다.

상권 분석은 선택한 지역과 분기의 세 지표를 조회합니다. 분기 목록에 지표가 표시돼도 해당 지역에는 통계 행이 없을 수 있습니다.

[통계 분기 목록 API](API.md#통계-분기-목록)

요약과 세부 탭은 같은 응답을 공유합니다.

상권 분석의 세부 탭은 선택 지역·분기의 일반·프랜차이즈 점포, 개업·폐업 점포, 주중·주말 추정매출액, 남성·여성 길 단위 유동인구를 그룹별 가로 막대로 표시합니다. 막대는 그룹마다 0부터 유효한 원본 최댓값까지 그립니다. 지역이나 분기가 바뀌면 상한이 달라질 수 있으므로 막대 길이는 같은 그룹 안에서 비교합니다.

각 막대 옆에서 정확한 값과 단위를 확인할 수 있습니다. 전체 점포 수, 개업률·폐업률, 당월 추정매출액·건수, 전체 유동인구는 숫자로 표시합니다. 유동인구는 길 단위 추정 규모입니다. 구성비와 분기 간 추세는 제공하지 않습니다.

막대에서 실제 0은 기준점에 표시하고 측정값 NULL은 자료 없음으로 안내합니다. 축에서 폭을 구분하기 어려운 양수는 값을 그대로 표시하고 폭이 작다는 안내를 붙입니다. 그룹에 값이 하나도 없으면 축을 표시하지 않습니다.

지표와 분기별로 로딩·오류·재시도·자료 없음을 구분합니다.

지역이나 분기가 바뀌면 이전 선택의 늦은 응답이 새 화면을 덮어쓰지 않도록 합니다.

화면에 핵심 측정값을 표시할 때만 소수 후행 0을 줄입니다.

실제 0은 0으로 표시하고, 행이 없는 경우와 행은 있으나 측정값이 없는 경우를 구분합니다.

상권 분석과 후보지 행정동 통계는 지표마다 실제 응답의 **서비스 DB 게시일**을 한국시간 날짜로 표시합니다. 행이 없거나 조회가 완료되지 않은 지표에는 날짜를 표시하지 않습니다. 제공기관은 서울신용보증재단이며, 상세 출처에서 서울 열린데이터광장의 지역 수준별 공식 데이터셋을 엽니다.

[API의 값과 출처](API.md#응답과-결측)

점포·추정매출·유동인구는 모두 `unverified` 상태입니다.

화면에는 비교 준비 상태를 한 번 설명하고 증감 수치·비율·방향은 보여 주지 않습니다.

전분기 비교용 조회는 미검증 상태에서 실행하지 않습니다.

[전분기 비교 검증 근거](ETL.md#전분기-비교-검증-근거)

공개가 검증된 입력에 쓸 계산은 BigInt(큰 정수 연산) 기반입니다.

증감량은 두 값 중 긴 소수 자릿수를 유지하고 증감률은 소수 첫째 자리까지 표시합니다.

정확히 절반이면 0에서 먼 쪽으로 반올림합니다.

이전 값이 0이고 현재 값이 양수면 증감량만, 두 값이 모두 0이면 변동 없음으로 처리합니다.

측정값 NULL·분기 누락·식별자 불일치는 숫자 공개를 제한합니다.

증감은 입지의 유불리로 해석해 표시하지 않습니다.

## 창업 후보지 비교

**후보지 분석**에서 지도 추가 모드 또는 검색 결과로 A·B·C 최대 3곳을 등록합니다.

지도 추가 모드에서는 클릭을 막을 수 있는 경계와 표식을 잠시 숨기고 적용된 지역 필터를 유지합니다.

추가 모드가 끝나면 경계와 표식이 다시 표시됩니다.

서울 자치구 경계가 중심점을 포함하는지 확인하며, 중복 위치나 서울 경계 밖 위치는 등록할 수 없습니다.

후보지의 이름·좌표는 브라우저 탭의 `sessionStorage`에 임시 저장합니다.

목록에서 지도 확인·이름 변경·삭제를 할 수 있습니다.

등록된 후보지가 없으면 추가 방법을 안내합니다. 한 곳은 상세 분석을 바로 표시합니다. 두세 곳은 지표별 비교를 먼저 보여 줍니다. 넓은 화면에서는 A·B·C를 표의 열에 배치하고, 좁은 화면에서는 지표마다 후보지를 세로로 표시합니다. 각 후보지의 상세 및 관리에서 지도 확인, 이름 수정, 삭제와 상세 자료에 접근할 수 있습니다.

주변 경쟁 환경에서는 공통 500m 또는 1km를 적용한 각 후보지의 독립 반경별 **전체 경쟁 카페 수**, 원천 기준년월, DB 게시일을 비교합니다. 거리순 최대 3곳은 각 후보지 상세에서 확인합니다.

별도 그룹에서 공통 선택 분기의 소속 행정동 전체 통계를 비교합니다. 점포·당월 추정매출은 카페 업종, 전체 유동인구는 업종 구분 없는 지역 기준으로 표시합니다. 각 지표의 DB 게시일을 따로 표시하며 상세 영역에서 공식 출처를 열 수 있습니다.

분기를 바꾸면 행정동 통계만 갱신합니다. 반경 내 경쟁 카페는 카페 API의 게시 데이터 기준으로 계속 표시합니다.

같은 행정동의 후보지는 통계 응답을 공유하며, 해당 동의 후보지가 남아 있으면 이름 수정이나 다른 후보지 등록·삭제로 다시 조회하지 않습니다.

소속 행정동을 유일하게 확정할 수 없으면 행정동 통계만 비교 불가로 안내합니다.

서울 소속을 확인한 위치의 반경 분석은 계속합니다.

후보지별 조회 오류·재시도·빈 결과를 구분합니다.

경쟁 카페와 주변 탐색에서는 결과마다 소상공인시장진흥공단의 **원천 기준년월**과 **서비스 DB 게시일**을 표시합니다. 기준년월이 없으면 확인 불가로 표시하며, 0곳을 반환한 정상 결과에도 게시 정보를 표시합니다. 주변 탐색은 지도 영역과 적용 구·동 경계, 또는 선택 지점의 독립 반경 범위를 구분합니다. 상세 출처에서 공공데이터포털의 공식 카페 원본을 엽니다.

현재 비교는 원본 통계와 경쟁 환경을 보여 주며 미검증 전분기 증감은 표시하지 않습니다.

## 다중 자치구 선택

검색 위치의 반경이 여러 자치구와 겹칠 때 개별 구나 해당 구 **모두**를 선택하는 흐름은 후속 요구사항입니다.

이 경우에도 겹치는 지역의 통계는 지역별로 제공하는 방향이며, 지역 전체 수치를 반경 실측값으로 표시하지 않습니다.

현재 화면은 자치구 한 곳과 그 아래 행정동을 고르는 필터, 별도의 반경 카페 조회를 제공합니다.
