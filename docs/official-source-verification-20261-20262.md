# 20261·20262 공식 원천 판본 후속 검증표

**확인일: 2026-11-05 KST. 공식 출력과 로컬 원본의 연결은 확인했지만, 두 분기의 산정·공간 기준은 아직 승인할 수 없습니다.** `NOT_APPROVED`, `sourceTrust=NOT_ESTABLISHED`, `R03_COMPLETE=false`와 Frontend의 세 지표 `unverified`를 유지합니다.

이 표는 [전분기 초기 검증](quarter-comparison-verification.md)의 DB·API 관찰과 [2026-11-03 공식 조사](score-20262-publication-readiness.md#2-검토-범위와-공식-근거별-확인-결과)에서 부족했던 **실제 파일 대응과 변경 공지의 적용 범위**를 보완합니다. 과거 테스트·R03 실행을 재수행한 것으로 기록하지 않습니다. 이메일은 발송하지 않았습니다.

### 공식 출력의 재확인 조건

공식 페이지에 노출된 다운로드 함수를 확인하고 해당 폼을 사용했습니다. 통계는 `POST https://datafile.seoul.go.kr/bigfile/iot/sheet/csv/download.do`, 경계 ZIP은 `POST https://datafile.seoul.go.kr/bigfile/iot/inf/nio_download.do?&useCache=false`입니다. 정식 근거 URL은 위 데이터셋 페이지이며, 다운로드 주소만으로 판본을 식별하지 않습니다. 인증키·로그인 세션·개인 계정 정보는 사용하지 않았습니다.

- 통계 공통: 페이지의 `infId`, `srvType=S`, `serviceKind=1`, `pageNo=1`, `strOrderby=STDR_YYQU_CD DESC`와 공개 폼의 조건을 사용했습니다. 6개 응답은 HTTP 200·CP949 CSV입니다.
- 자치구 3종·행정동 인구: `strWhere`는 빈 문자열입니다.
- 행정동 점포·매출: 페이지 기본 `strWhere`는 ` AND STDR_YYQU_CD > TO_CHAR(ADD_MONTHS(now(), -12), 'YYYY')`입니다. 이 동적 조건의 **조회 당시** 결과가 20251~20262이며, 장래에도 동일 기간·바이트를 보장하지 않습니다. ‘2021년 이후 제공’이라는 공지와 기본 화면의 최근 기간 내보내기는 서로 다른 범위입니다.
- 경계: `infId=OA-22160` 또는 `OA-22161`, `infSeq=3`, `seq=1`을 사용했습니다. 공식 응답 바이트를 메모리로 읽었으며 파일 저장·압축 해제 파일 생성·적재는 하지 않았습니다.

## 3. 실제 파일·DB 대조와 비교 가능성 판단

기존 자치구 3개 `--probe`의 함수를 `probe:true`로 직접 실행했습니다. 점포 54,765행·매출 33,803행·인구 550행의 기존 기대 행 수와 일치했고 거부 행 0, `databaseChecked=false`, `batchCreated=false`, `loadedRows=0`을 확인했습니다. 행정동 3종도 기존 `readStoreSource()`·`readSalesSource()`·`readFootTrafficSource()`로 전체 형식을 읽었습니다. 새 도구·적재·마이그레이션·임시 검증 파일은 만들지 않았습니다.

DB는 로컬 개발 인스턴스에서 `REPEATABLE READ READ ONLY`, 실제 `transaction_read_only=on`·`transaction_isolation=repeatable read`를 확인하고 종료 시 `ROLLBACK`했습니다. 마지막 대조 트랜잭션에서 두 분기의 대상 통계 **2,692행**과 각 행의 실제 출처를 읽었습니다. 기존 판독기의 정규화된 CSV 필드(점포 7개·매출 4개·인구 3개)와 DB의 정확한 문자열/NULL을 비교해 필드·배치 불일치, CSV에만 있는 행, DB에만 있는 행 모두 0건입니다.

- 구 3종 각각 25지역×2분기=50행, 동 점포·인구 각각 425×2=850행, 동 매출 421×2=842행입니다. [초기 커버리지 표](quarter-comparison-verification.md#확인-범위와-결과)와 수는 같지만, 이번 새 근거는 **실제 원본 필드와 DB 출처의 전체 대상 행 대조**입니다.
