# 웹 디자인 시스템

사용자에게 표시하는 서비스명은 **여기 창업해도 돼?**입니다. 저장소와 프로젝트는 **RecycleYoungs**로 부릅니다. 서비스를 소개할 때는 공공데이터 기반 창업 입지 탐색 서비스라는 설명과 기존 핵심 슬로건인 “창업할 곳, 감으로만 고르지 마세요.”를 사용합니다.

## 로고와 파비콘

[BrandLogo](../apps/web/src/shared/ui/brand-logo.tsx)의 기본 워드마크는 지도 핀 심볼과 서비스명 텍스트를 함께 사용합니다. 단독 심볼에는 `variant="symbol"`을 지정하며, 접근 가능한 이름은 서비스명입니다. 워드마크에서는 텍스트로 이름을 읽고 SVG를 장식으로 처리합니다. 기본 심볼 크기는 24px이며 `size`로 바꿀 수 있습니다. 어두운 배경에서는 `background="dark"`로 밝은 핀과 어두운 물음표를 사용합니다.

[favicon.svg](../apps/web/public/favicon.svg)는 정사각형 캔버스에 같은 두 도형을 담습니다. 파비콘은 브라우저 색상 선호에 따라 두 색을 교체하고, 웹의 `BrandLogo`는 표시할 배경에 맞춰 색을 지정합니다. 홈 버튼처럼 기능을 나타내는 아이콘은 해당 기능의 기존 Lucide 아이콘과 레이블을 사용합니다.

## 색상과 상태

[tokens.css](../apps/web/src/shared/styles/tokens.css)의 `--brand-*`는 팔레트입니다. 컴포넌트는 [index.css](../apps/web/src/shared/styles/index.css)에서 Tailwind와 연결한 역할 토큰을 우선 사용합니다.

| 역할 | 토큰 | 색상 |
| --- | --- | --- |
| 제목, 주요 강조 | `primary` | `#173629` |
| 주요 행동 기본·hover·active | `action` · `action-hover` · `action-active` | `#8BE26E` · `#77D657` · `#66C747` |
| 연한 선택 배경 | `accent` | `#E6F9DF` |
| 페이지·카드·입력 / 보조 표면 | `background` · `card` / `muted` · `secondary` | `#FFFFFF` / `#F4F5F3` |
| 일반 / 보조 텍스트 | `foreground` / `muted-foreground` | `#202824` / `#59635D` |
| 카드 경계 / 연한 입력 경계 팔레트 | `border` / `input` | `#E0E5DF` / `#D3DBD1` |
| 조작에 필요한 컨트롤 경계 / 키보드 포커스 | `control` / `ring` | `#7D887F` / `#3C7844` |
| 성공 / 주의 / 오류 | `success` / `warning` / `destructive` | `#2E693A` / `#744A12` / `#A12622` |
| 선택한 후보지 | `candidate-selected` | `#4338CA` |

일반 안내와 미제공 값은 기본 또는 보조 텍스트로 표시합니다. 부분 게시와 자료 갱신 안내에는 주의 색을, 실제 실패에는 오류 색을 사용합니다. 각 상태는 텍스트와 접근성 속성으로도 확인할 수 있어야 합니다. 0과 자료 없음, 조회 오류, 브랜드 추정과 미확인은 기존 표기대로 구분합니다. 지도에서 선택한 후보지에는 요약의 **지도 선택됨**과 비교 이름의 밑줄을 함께 표시합니다.

일반 텍스트는 4.5:1, 큰 텍스트와 조작에 필요한 경계·포커스 표시는 3:1 이상의 명암 대비를 확인합니다. 옅은 카드 경계나 배경은 화면을 정리하는 보조 수단입니다. 지도 SDK에 직접 전달하는 마커 SVG·경계·클러스터 옵션은 지도 위젯에서 관리합니다. DOM으로 렌더링하는 클러스터 버튼에는 공통 색상 토큰을 사용할 수 있습니다.

## 글자와 컴포넌트

- 웹 공통 글꼴은 Geist Variable, Apple SD Gothic Neo, Malgun Gothic, 시스템 sans-serif 순입니다. 랜딩 제목은 반응형 크기를 따릅니다. 패널 제목은 `text-base`, 카드와 섹션 제목은 `text-sm`과 `font-semibold`를 기본으로 삼습니다. 보조 설명과 출처는 `text-xs`와 `text-muted-foreground`를 사용하며 탐색 패널의 기존 가독성 보정이 적용됩니다.
- 통계 수치, 그래프의 값과 축, 후보지 비교의 수치에는 `tabular-nums`를 사용합니다. 큰 값은 줄바꿈을 허용하고 원본 값·단위·정밀도는 기존 표기 규칙을 따릅니다.
- [Button](../apps/web/src/shared/ui/button.tsx)의 `default`는 주요 행동, `secondary`는 보조 행동, `outline`은 경계가 필요한 보조 조작, `ghost`는 시각적 강조가 낮은 조작, `destructive`는 삭제에 사용합니다. Dock은 `navigation`으로 현재 메뉴를 표시합니다. 키보드 포커스는 2px 윤곽선을 사용하고 모션 감소 설정에서는 버튼 전환과 누름 이동을 제거합니다.
- [NativeSelect](../apps/web/src/shared/ui/native-select.tsx)는 기존 네이티브 역할과 키보드 동작을 사용합니다. 16px 화살표와 우측 12px 간격, 내부 좌우 12px·40px 여백을 유지합니다. 일반 입력과 textarea는 `form-control`로 동일한 테두리·포커스를 사용합니다. 검색 입력이 키보드 포커스를 받으면 검색창 전체에 윤곽선을 표시하고, 제출 버튼은 자체 포커스 표시를 사용합니다.
- 카페, 통계, 후보지 카드는 `bg-card`, `text-card-foreground`, `border`를 공통으로 사용합니다. 조밀한 목록에는 `rounded-lg`, 독립적인 통계·비교 카드에는 `rounded-xl`를 적용합니다. 배치·내부 여백은 각 화면에서 정하고, 떠 있는 입력과 필터·검색 결과는 공통 `--shadow-control` 또는 `--shadow-popover`를 사용합니다.

## 지도와 탐색 패널

- **카페**는 진한 녹색 핀, 흰 커피잔과 외곽선을 사용합니다. 선택하면 같은 크기와 앵커에서 이중 외곽선을 표시하고 목록 카드에도 왼쪽 강조선을 표시합니다. 정보창은 기존 점포명·주소·업종·브랜드·거리 정보를 사용하며 닫기와 포커스 복귀를 지원합니다.
- **클러스터**는 Action 배경, Primary 숫자와 안쪽 경계, 흰색 바깥 테두리를 사용합니다. 지름은 48·56·64px이며 숫자는 중앙에 고정폭으로 정렬합니다. 숫자는 현재 조회된 지도 마커가 묶인 수입니다.
- **후보지**는 A·B·C가 적힌 사각 깃발형 마커입니다. 기본은 Slate이며 선택하면 보라색과 안쪽 흰색선을 사용합니다. 카드와 비교표에도 동일한 선택 색과 `지도 선택됨` 안내를 사용합니다. [마커 리소스](../apps/web/src/widgets/explore-map/map-marker-style.ts)
- **반경 중심·검색·현재 위치**는 각각 조준점, 호박색 돋보기, 파란 점으로 구분합니다. 반경 원은 기존의 옅은 녹색 채움과 점선 경계를 사용합니다. SVG의 색과 좌표 앵커는 지도 위젯이 관리하고, DOM의 정보창과 클러스터 버튼은 공통 토큰을 사용합니다.
- **상권 분석**의 핵심 지표는 연한 선택색 배경으로 묶고, 상세 지표와 그래프는 카드 표면을 사용합니다. 그래프는 같은 계열의 녹색 막대를 사용하며 항목 이름, 정확한 수치, 단위와 각 그룹의 축을 함께 표시합니다.

## 랜딩 서비스 프리뷰

히어로와 장소 검색 프리뷰에는 자체 SVG 지도 개념도와 실제 제품 UI를 조합합니다. 모바일 히어로에서는 개념도 위로 주변 탐색 시트를 배치합니다. 개념도는 가상의 도로와 녹지를 사용하며 서비스의 마커 스타일을 반영합니다.

카페 목록, 장소 검색 입력창, 대표 점포 그래프와 후보지 비교표에는 개발 환경의 실제 UI를 캡처한 WebP를 사용합니다. 카페 원천 기준년월, 통계 기준 분기와 게시일은 조회 화면 기준으로 표기합니다. 캡처를 바꿀 때는 상권 핵심 지표와 후보지별 행정동·경쟁 카페 수 요약의 텍스트도 같이 갱신합니다.

카카오 지도 타일을 포함한 전체 화면은 로컬 검증 기록으로 관리합니다. 온라인 서비스의 지도는 실시간 API를 사용하도록 카카오에서 안내합니다. 공개 WebP에는 RecycleYoungs의 패널이나 입력창만 담습니다. [캡처 이미지 사용에 관한 카카오 답변](https://devtalk.kakao.com/t/topic/146903/2)

히어로에는 모바일 전용 소스와 로딩 우선순위를 지정하고 하단 기능 프리뷰는 지연 로딩합니다. WebP를 교체할 때는 이미지의 실제 너비·높이, 대체 텍스트, 캡션을 확인합니다. 랜딩 소개는 서울 카페에 제공하는 실제 검색·조회·저장·비교 기능을 설명합니다.
