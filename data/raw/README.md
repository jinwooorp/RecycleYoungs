# 원본 데이터 입력

현재 입력 위치는 `data/raw/dataset/`입니다. 전달받은 `dataset.zip`을 이 디렉터리(`data/raw/`)에 압축 해제하면 ZIP 내부의 `dataset/` 폴더 아래에 CSV 6개가 배치됩니다.

원본 파일은 수정하지 않고 보존합니다. 원본 CSV와 ZIP은 Git에서 제외하며 `dataset/.gitkeep`으로 폴더 경로만 공유합니다. 새로 clone한 환경에서는 원본 자료를 별도로 확보해야 합니다.

서울시 CSV는 CP949, 소상공인 CSV는 UTF-8-SIG입니다. 전체 파일 목록·기간·건수·좌표계 확인 상태는 [데이터 목록](../../docs/data-catalog.md), 해시는 [manifest](../manifest.json)를 확인합니다.

`길단위인구-서울시` CSV는 원본으로 보관하지만 위치별 분석 ETL 대상에서는 제외합니다. 영역 CSV의 좌표계는 원천 메타데이터 확인 전 확정하지 않습니다.

파일 교체 시 기존 입력을 백업하고 출처·기준 기간·해시를 갱신합니다. 같은 파일명으로 여러 스냅샷을 보관할 때는 ETL의 입력 경로를 명시해야 합니다.
